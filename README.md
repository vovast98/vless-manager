# VLESS Manager

Приложение для управления VLESS-серверами по SSH на Windows и macOS.

- Установка входного и выходного сервера на Debian/Ubuntu с systemd.
- TCP/RAW, XHTTP, gRPC, WebSocket, HTTPUpgrade; совместимые Reality/TLS.
- Автоматическая генерация UUID, ключей Reality и ссылок подключения.
- Перенаправление через VLESS-ссылку, геосписки и ручные исключения.
- Клиенты, конфиг JSON, резервные копии и откат при ошибке применения.
- Проверка ключа SSH; режим «Только чтение» при запуске.
- Пароли: Windows DPAPI или системная Связка ключей macOS.

## Готовая сборка macOS через GitHub Actions

Во вкладке **Actions → Build macOS app** откройте успешный запуск и скачайте
артефакт **VLESS-Manager-macOS**. Внутри находится ZIP приложения и отчёт
проверки. Распакуйте внутренний ZIP и перенесите `VLESS Manager.app` в Applications.
Для скачивания артефакта закрытого репозитория нужно войти в GitHub.
Сборка также запускается вручную кнопкой **Run workflow**.

Приложение собирается для архитектуры macOS runner, указанной в отчёте.
Подпись локальная ad-hoc, нотариализации Apple нет.
Workflow использует минуты GitHub Actions; использование сверх включённого
в тариф лимита может тарифицироваться согласно настройкам аккаунта.

## Сборка на своём компьютере

macOS: Python 3.12 с tkinter, затем `bash app/build_macos.command`.
Подробности: [инструкция macOS](docs/macos.md).

Windows: Python 3.12 x64 с tkinter, затем `powershell -File app/build.ps1`.

Запуск исходников после установки зависимостей: `python app/main.py`.
Тесты: из каталога `app` выполните `python -m unittest discover -s tests -v`.

## Данные и ограничения

Рабочие профили, пароли и SSH-ключи в репозиторий не включены.
На macOS профили находятся в `~/Library/Application Support/VLESSManager`,
на Windows — `%APPDATA%/VLESSManager`. Пароли Windows на Mac не переносятся.
Поддерживается один JSON-конфиг Xray; установки через `confdir` не поддерживаются.
Применение конфига перезапускает Xray и разрывает текущие соединения.

В этой версии нативная macOS-сборка подлежит проверке первым запуском Actions.
Настоящая Связка ключей и публичная выдача сертификата ACME не проверялись
автотестами. Тесты не подключаются к рабочим серверам.
