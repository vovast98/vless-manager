# VLESS Manager 1.2.0 для macOS

Это исходники и скрипт сборки на Mac, а не готовый проверенный .app.
Поддерживаются Mac с Apple Silicon и Intel; сборка создаётся для архитектуры
запущенного Python. Требуется macOS 11 или новее и Python 3.12 с tkinter.

1. Установите Python 3.12 для macOS с https://www.python.org/downloads/macos/.
   Используйте установщик universal2 с tkinter. Если установщик предлагает
   `Install Certificates.command`, выполните его для настройки сертификатов Python.
2. Распакуйте архив в обычную папку, например Downloads или Documents.
3. Откройте Terminal в распакованной папке и выполните:

   ```bash
   bash app/build_macos.command
   ```

Скрипт скачает зависимости в локальное окружение `.venv-macos`, выполнит тесты,
соберёт приложение и проверит его запуск в режиме без подключения к серверам.
Сборка требует доступа к интернету для установки зависимостей и активного
графического сеанса macOS. Не запускайте её через sudo.

Результаты появятся в `app/dist/`:

- `VLESS Manager.app` — перетащите в Applications;
- `VLESS-Manager-1.2.0-macOS-arm64.zip` или `…-x86_64.zip`;
- `macos-validation.json` — результаты проверки запуска.

Приложение получает локальную подпись ad-hoc. Подписи Developer ID и
нотариализации Apple нет; macOS может запросить разрешение на открытие.
Для первой проверки можно запустить исходники:

```bash
app/.venv-macos/bin/python app/main.py
```

При ошибке сборки сохраните текст из Terminal. Не отключайте Gatekeeper целиком.

## Возможности

Создание входного и выходного сервера, перенаправление через VLESS-ссылку,
геосписки, ручные исключения, клиенты, готовые ссылки, JSON и резервные копии.
Транспорты: TCP/RAW, XHTTP, gRPC, WebSocket и HTTPUpgrade. Reality для TCP,
XHTTP и gRPC; TLS для всех пяти; Vision для TCP. По умолчанию включён режим
«Только чтение». Применение изменений требует просмотра различий.

## Профили и пароли

Профили и проверенные ключи SSH находятся в
`~/Library/Application Support/VLESSManager/`.
Пароли сохраняются в системной «Связке ключей», сервис `VLESSManager.SSH`.
В JSON хранится только ссылка на запись. При отключении сохранения пароля,
очистке поля с последующим сохранением или удалении профиля запись удаляется
из Связки ключей; ошибка удаления отображается в журнале.
macOS может запросить доступ к Связке ключей.

Зашифрованные пароли профилей Windows не переносятся на Mac: их нужно ввести
заново. Пользовательские ключи SSH также нужно выбрать по пути на Mac.

Исходники адаптированы и проверены тестами в Windows. Реальная Связка ключей,
нативная сборка и запуск на macOS требуют проверки на Mac. Скрипт сборки
выполняет такую проверку запуска, но не сохраняет тестовые пароли в настоящую
Связку ключей и не подключается к рабочим серверам.
